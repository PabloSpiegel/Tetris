Tetris
======

## Building instructions
At first, you have to install [allegro](https://www.allegro.cc/files/) and its dependencies.  
On the _makefile_ set the variable ALLEGRO_PATH to your current Allegro installation

##Compiled executables
- tetris-cli: prints the tetris on the terminal on a test environment without real time
- tetris: real time tetris game with graphics
- allegro test: opens a window showing a cube that can be moved with the keys to test the allegro library
